# Política de segurança

Este repositório é um showcase público sanitizado do MCMV RJ Platform Showcase. Nenhuma credencial, secret, dado de cliente ou informação administrativa privada da aplicação real deve ser adicionada. Todos os dados demonstrativos devem ser fictícios.

A fonte principal das regras de segurança está em [docs/security.md](docs/security.md), incluindo as proibições de copiar `.env`, tokens, API keys e URLs administrativas privadas ou usar bancos e webhooks de produção.

Para relatar uma vulnerabilidade ou possível exposição, comunique o proprietário por um canal privado acordado. Não inclua informações sensíveis em issues ou PRs públicos. O tratamento de credenciais expostas deve seguir [docs/security.md](docs/security.md).
